# EjerciciosPracticosJavaScript
Tarea de la semana 3
## Descripción
Implementación de funciones matemáticas avanzadas en JavaScript con Node.js, aplicando recursividad, estructuras de control y programación asíncrona.
Funciones Implementadas
## 1. Serie de Fibonacci
Calcula números de la secuencia de Fibonacci donde cada número es la suma de los dos anteriores.

fibonacci(5) → 5

## 2. Factorial
Calcula el producto de todos los números enteros positivos desde 1 hasta n.

factorial(5) → 120

## 3. Verificación de Números Primos
Determina si un número es primo (solo divisible por 1 y sí mismo).

esPrimo(7) → true

## 4. Descomposición en Factores Primos
Descompone un número en sus factores primos.

factoresPrimos(18) → [2, 3, 3]
